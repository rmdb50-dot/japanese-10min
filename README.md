# 매일 10분 일본어 학습 앱

스마트폰 홈 화면에 설치할 수 있는 PWA입니다. HTTPS 호스팅에서 실행하면 오프라인 기본 실행과 새 버전 알림을 지원합니다.

## 스마트폰 설치

1. GitHub Pages 배포 주소를 Android의 Chrome 또는 Samsung Internet으로 엽니다.
2. 브라우저 메뉴에서 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
3. 홈 화면의 '일본어 10분' 아이콘으로 실행합니다.

## 다음 버전 자동 업데이트

- 수정한 웹 파일을 같은 GitHub 저장소에 다시 올리면 GitHub Pages가 사이트를 다시 게시합니다.
- 새 버전을 배포할 때 service-worker.js 안의 CACHE_NAME 숫자도 올려야 합니다.
- 앱을 다시 열면 업데이트 안내가 나타나며, '지금 업데이트'를 누르면 새 버전으로 전환됩니다.

## 데이터 및 주의사항

- 학습 진도는 해당 기기/브라우저의 로컬 저장공간에 저장됩니다. 다른 기기와 자동 동기화되지는 않습니다.
- 브라우저의 사이트 데이터 삭제 시 학습 기록이 사라질 수 있습니다.
- 저장소는 공개로 설정되어 있으므로 개인정보나 비공개 자료를 업로드하지 마세요.
